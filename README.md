# Human-Centered AI LAB

Bilingual website for Human-Centered AI LAB at the Global Institute of Future Technology, Shanghai Jiao Tong University.

Website: https://sivan666666.github.io/hcai-lab/

## Editing

- `app.js`: bilingual text, member directory, navigation and page templates.
- `publications.js`: publication information and resource links.
- `style.css`: layout and visual styles.
- `assets/`: website images and videos.

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the website. `.nojekyll` keeps this a plain static site.

Preview locally with `python -m http.server 4173`.

Research figures and videos belong to their respective authors. Institutional branding belongs to Shanghai Jiao Tong University and its Global Institute of Future Technology.
